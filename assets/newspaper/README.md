# Fictional Newspaper Clippings

This folder is for custom-made fictional clippings, not real news cuttings. Planned artifacts:

- 1998 report on the fire and Mayor Thomas Wren's death.
- 2023 report about the second nearby fire and review of the 1998 file.
- 2026 report on the third nearby fire that triggers the current investigation.
- Optional notice about Ashbourne's land-development project.

All headlines, publication names, dates, bylines, body text, and visual layouts must match the master timeline. Reports must not state that arson is proven.
