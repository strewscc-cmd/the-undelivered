# Letters

Place each final letter here as its own Markdown file after the story text has been fully reconciled with the Master Timeline.

Planned files: F01–F15. See [Master Letter Register](../../docs/05-master-letter-register.md).

Every letter file should contain:
- ID and title
- author and intended recipient
- date written
- date mailed/processed/received/discovered, where relevant
- full letter text
- clue purpose and cross-references
- what it supports and what it cannot prove
- reading/inference objective
- continuity status

Do not publish placeholder drafts as final evidence.
