## Required metadata for every official document

- Document ID and title
- Issuing authority / author
- Original date
- Date discovered (if different)
- Reference number
- Intended recipients or authorized readers
- Whether the document is original, a copy, damaged, or reconstructed
- Facts directly recorded
- Inferences permitted
- Inferences not permitted
- Cross-references to other evidence
- Puzzle(s) that use it

## E13 — Retention Note: required constraints

The final note must identify the held letters with matching references (initial placeholder references may be used during drafting but must be frozen before scripts/puzzles are finalized). It must state enough to establish that specified letters were held from normal processing and why the investigator links the entries. It should include provenance/signature/attribution so Silas's role is supported where appropriate. It cannot establish that Silas knew about the fires or that the person who requested retention caused a fire.

## Fictional records warning

All municipality, police, postal, corporate, and newspaper documents are fictional game assets. They should not imitate a real person's actual records or imply a real company committed arson.
